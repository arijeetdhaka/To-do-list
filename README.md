# 📝 To-Do List

A simple and clean To-Do List web application to help you organize your daily tasks.  
Add tasks, mark them as completed, and delete them — all with a neat user interface.

---

## 🚀 Features

✔ Add new tasks  
✔ Mark tasks as completed / uncompleted  
✔ Remove tasks instantly  
✔ Simple & responsive UI  
✔ Lightweight — No backend required
